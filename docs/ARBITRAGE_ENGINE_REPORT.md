## STEP 7 — User Unlock / VIP Flow

### What users see before vs after paying:

**Before unlock (locked view)**: Shows match, yield %, profit estimate, required capital, team names, league, and basic odds. The AI Analysis section is blurred.

**After unlock (unlocked view)**: Shows the same data PLUS:
- AI analysis values (computed locally from confidence and isk_level DB fields — NO actual AI)
- AI recommendation text (static hardcoded text)
- Stake allocation (computed as equired_capital * 0.52 and equired_capital * 0.48)
- Historical results section (3 static hardcoded data points: 83%/4.2%/91% — same for ALL opportunities)

**VIP page** (src/app/(main)/vip/page.tsx): Shows level tiers (Explorer through Legend) with benefit descriptions. VIP levels control access to features like "Daily Signals" count, but the "signals" are just the same seeded opportunities.

### Behind the paywall is the same static data.
The unlock_price in the unlocks table is set to equired_capital from the opportunity record. The user pays this amount and a row is added to unlocks. The opportunity detail page then checks the unlocks table to determine if the blur overlay should be removed. But the actual data values (roi, profit, odds, etc.) are exactly the same whether locked or unlocked — they were already fetched from the API.
